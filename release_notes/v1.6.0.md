## SetupTTS v1.6.0

Turn any text into natural-sounding MP3 audio with Microsoft's neural voices — from a short note to a 12-hour audiobook. No Python, no terminal.

> Speech is generated by Microsoft's online speech service, so an internet connection is required. Text preparation, progress tracking and file writing happen on your computer.

---

### What's new

#### Long audiobooks are safer
- **No more silently shortened audio when the connection drops.** If the connection to the speech service closed partway through a section, the partial audio used to be accepted as complete, leaving a gap in the finished book. Every section is now checked against the speech service's own timing information and re-requested if anything is missing.
- **Jobs that could never finish now complete.** A paragraph break that happened to fall on a section boundary left a one-character gap that made the final safety check refuse the file on every attempt, including every resume.
- **Resume really resumes.** For some punctuation-heavy texts, Resume silently started over from the beginning and discarded the saved progress. It now continues from where it stopped.
- **Saved progress is no longer deleted after a week.** Unfinished jobs are kept for 60 days, and the job you are resuming is never touched.
- **A too-short result never replaces your file.** The final length check now runs before the file is saved. If it fails, your existing file is left unchanged and the new audio is kept as “name (incomplete).mp3” so you can listen to it.
- **Disk full or a locked file mid-job can be resumed**, with a plain explanation instead of a raw error.
- **A brief internet hiccup at the start of a job is retried** instead of failing immediately.
- **Your finished audio is never overwritten by surprise.** If the file already exists you choose **Keep Both** (saves as “name (2).mp3”) or **Replace**.

#### Easier to use
- **Standard and Multilingual voices are told apart** — “Andrew” and “Andrew (Multilingual)” used to appear as two identical entries.
- **Clearer Active Jobs**: plain-language stages (“Generating audio”, “Connection problem — retrying”, “Finalizing the MP3 file”), “Chunk 82 of ~194”, speed, and a time-left estimate once it is reliable.
- **Understandable error messages** with **Resume** and **Open Logs Folder** buttons. Technical details are one click away under “Show Details”.
- **Recent Conversions shows the audio length**, and warns if a file has been moved or deleted.
- **Speed control**: “Normal (0%)” label and a one-click **Reset**.
- **File names are checked before a job starts** (characters Windows can't use, missing or read-only folders, over-long paths).
- **Text files from Windows Notepad open correctly** (UTF-16 and ANSI files used to import as garbage), and **Clear Text can be undone**.
- **Settings** is organised into General, Voice, Logs & Troubleshooting and About, with **Open Current Log**, and shows the version. The version is also in the window title.
- **Keyboard**: Ctrl/⌘+O open, Ctrl/⌘+Enter generate, Ctrl/⌘+, settings; visible focus when using Tab.
- **Better readability**: higher-contrast secondary text and a real dropdown arrow.
- **Only one copy of SetupTTS runs at a time** — opening it again brings the existing window forward.
- **Unfinished jobs** can be resumed or discarded from one menu, and resumed to a new folder if the original one is gone.
- **The voice list works offline** from the last list downloaded, so your voice choice is kept when the connection is down at startup.

#### Under the hood
- Fixed leaked database connections (held file locks on Windows).
- Lower memory use at the end of long jobs; less work on the UI thread while typing in very long texts.
- The log file is now `setuptts.log`; existing logs are carried over.
- The packaged apps are tested on every release: CI launches the built macOS app, the installed Windows app and the portable Windows EXE, checks bundled files, secure connections and voice loading, and generates a short sample.

### Download

| Platform | File | Notes |
|----------|------|-------|
| **macOS 15+** (Apple Silicon) | `SetupTTS-macOS.dmg` | Drag to Applications |
| **macOS 15+** (Apple Silicon) | `SetupTTS-macOS.zip` | Alternative — unzip and open |
| **Windows 10/11** (64-bit) | `SetupTTS-Windows-Installer.exe` | Recommended — installs and adds a Start Menu shortcut |
| **Windows 10/11** (64-bit) | `SetupTTS-Windows-Portable.zip` | No installation — unzip and run |

Intel Macs and macOS 14 or earlier are not supported by this build. (The Qt version this build uses requires macOS 15 — v1.5.8 stated macOS 12 but its bundled Qt libraries already required macOS 15.)

### Installing on macOS
1. Open `SetupTTS-macOS.dmg` and drag **SetupTTS** into **Applications**.
2. Open SetupTTS. The app is not notarized, so the first time macOS may refuse to open it: go to **System Settings ▸ Privacy & Security**, scroll down and click **Open Anyway**.

### Installing on Windows
1. Run `SetupTTS-Windows-Installer.exe`. If SmartScreen appears, click **More info ▸ Run anyway** (the installer is not code-signed).
2. Installing over an older version replaces it — your settings, history and unfinished jobs are kept.

> **Using the portable version?** Delete old copies of `SetupTTS.exe` so you don't open an outdated one by mistake. The version number is shown in the window title.
