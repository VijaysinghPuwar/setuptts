## SetupTTS v1.6.2

A reliability release. The headline fix is for **Andrew and the other "slower" voices** (Andrew Multilingual, Ava Multilingual and similar), which kept stopping with *"The speech request stalled after partial audio"*. It also folds in every fix from v1.6.1, which was never published separately.

> Speech is generated by Microsoft's online speech service, so an internet connection is required. Text preparation, progress tracking and file writing happen on your computer.

---

### What's fixed

**Voices that stream slowly (Andrew and the Multilingual voices)**
- **Andrew no longer stops with "stalled after partial audio".** Some voices send their audio several times slower than others. SetupTTS gave every part of a job the same short time limit, sized for the fast voices, so it cut off Andrew while audio was still arriving and then retried the same part again and again. The time limit is now based on how much speech each part contains and on the speed you chose. A connection that has really stopped is still detected within seconds.
- **Long Andrew jobs are faster.** SetupTTS treated any part that took more than half a minute as "slow" and kept splitting the book into smaller and smaller pieces. That meant many more requests, and each request is another chance for something to go wrong. It now only slows down when the voice really can't keep up.
- **Long jobs no longer fail at the very end with "the recorded chunks do not cover the full source text".** In versions before 1.6.0 this happened when a split fell inside a blank line between paragraphs. Resuming hit the same spot every time. This affected many Andrew audiobooks.

**Resuming saved jobs**
- **Resume works for jobs started with "Use anyway".** If you chose to use a voice that doesn't match the text's language, every Resume used to fail straight away.

**Text and languages**
- **Chinese and Japanese are split at the ends of sentences.** Before, each piece was cut every ~1,400 characters, often mid-sentence or mid-word, which caused audible breaks.
- **Words with hidden hyphens stay whole.** Text copied from e-books and web pages often has invisible "soft hyphens", so "inter­national" was read as "inter national".
- **Symbols and decimals are kept.** ° (as in "180°C"), ©, ® and ™ are no longer dropped, and ".5" and ".NET" are no longer merged into the word before them.
- **Persian and Indic text keeps its joining marks**, so words are shaped and pronounced correctly.
- **Text files open in their real encoding.** Russian (Windows-1251), Japanese (Shift-JIS), Chinese (GBK/Big5), Korean, UTF-32 and Unicode files saved without a BOM were opened as garbled text and read aloud as gibberish.
- **Very long documents no longer freeze the window while you type.** A 20 MB document used to pause the app for about 35 seconds after every edit.
- **Long passages without paragraph breaks are prepared much faster.**

**Settings, history and files**
- **Settings shows which version you are using**, in the title and at the top of the dialog. **Copy Diagnostic Info** copies your version, operating system and log location, ready to paste into a bug report.
- **The default save folder in Settings now works.** The folder you picked was ignored, and the next export then overwrote your choice.
- **A damaged settings file no longer stops SetupTTS from starting.** Only the bad value is reset; your other preferences are kept.
- **Settings are saved even if the settings file is read-only** or is briefly locked by antivirus or OneDrive.
- **SetupTTS starts normally, and keeps your history, when another copy (such as an old portable version) is open.** On Windows it failed to start; on macOS history could be set aside as damaged.
- **The same file can't be exported twice at once** when the names differ only in capital letters ("Book.mp3" / "book.mp3").
- **"Keep both" keeps numbers that are part of a file name**, so "Annual Report (2024)" becomes "Annual Report (2024) (2)", not "Annual Report (2)".

**From v1.6.1 (Windows)**
- **Voices load on PCs with antivirus HTTPS scanning** (Avast, AVG, Kaspersky, ESET, Bitdefender and others) and on many school and office networks. SetupTTS now trusts the certificates in the Windows certificate store.
- **A proxy set in Windows Settings is now used.**
- **Settings fits on screen**, and opening SetupTTS a second time brings the existing window to the front.

**Better logs for troubleshooting**
- Errors that used to disappear without a trace in the Windows app are now written to the log, and a crash of the app itself is recorded in `crash.log`.
- Each session records the app version, operating system and library versions.
- Each job ends with a one-line summary of retries, failures and timing, so problems can be diagnosed from a single log.

Your settings, history and unfinished jobs are kept when you update.

### Download

| Platform | File | Notes |
|----------|------|-------|
| **macOS 15+** (Apple Silicon) | `SetupTTS-macOS.dmg` | Drag to Applications |
| **macOS 15+** (Apple Silicon) | `SetupTTS-macOS.zip` | Alternative — unzip and open |
| **Windows 10/11** (64-bit) | `SetupTTS-Windows-Installer.exe` | Recommended — installs and adds a Start Menu shortcut |
| **Windows 10/11** (64-bit) | `SetupTTS-Windows-Portable.zip` | No installation — unzip and run |

Intel Macs and macOS 14 or earlier are not supported by this build.

### Installing on macOS
1. Open `SetupTTS-macOS.dmg` and drag **SetupTTS** into **Applications**.
2. Open SetupTTS. The app is not notarized, so the first time macOS may refuse to open it: go to **System Settings ▸ Privacy & Security**, scroll down and click **Open Anyway**.

### Installing on Windows
1. Run `SetupTTS-Windows-Installer.exe`. If SmartScreen appears, click **More info ▸ Run anyway** (the installer is not code-signed).
2. Installing over an older version replaces it — your settings, history and unfinished jobs are kept.

> **Using the portable version?** Delete old copies of `SetupTTS.exe` (check your Desktop and Downloads) so you don't open an outdated one by mistake. The version number is shown in the window title and in **Settings**.
