## SetupTTS v1.8.0

**Offline voices can run on an NVIDIA graphics card on Windows (beta).**

---

### New

- **NVIDIA GPU support for offline voices (Windows, beta).** On a PC with a GeForce RTX 20-series / GTX 16-series card or newer and NVIDIA driver 580 or later, offline (Piper) voices can run on the graphics card instead of the processor. Open **Settings ▸ Graphics card ▸ GPU Settings…** and choose **Download GPU support**. This is a one-time download of about 1.3 GB of NVIDIA's CUDA libraries, kept out of the installer so it stays the same size. The download can be stopped and resumed.
- **Automatic, or your choice.** After the download, SetupTTS times the same voice on the processor and on the card. In **Automatic** mode (the default) the card is used only if it is clearly faster, at least 1.25×. A modest card paired with a strong processor stays on the processor. **Graphics card** and **Processor** can also be chosen by hand. Changes take effect the next time SetupTTS starts.
- **Safe if the card misbehaves.** If the card fails during a job, the job carries on on the processor and the log says why. If the GPU files are damaged, for example when antivirus quarantines one, SetupTTS starts on the processor instead of losing its offline voices. **Remove GPU support** frees the space again.
- **No NVIDIA card? Nothing changes.** On a PC with only a processor, or AMD or Intel graphics, Settings simply says offline voices run on the processor.

### Unchanged on Mac

macOS does not have this option, and nothing about how offline voices run on a Mac has changed. On a MacBook Pro M5 the same voice ran at the same speed before and after this release: about 203 characters per second either way, averaged over alternating runs.

### For developers

- `scripts/local_benchmark.py` turns a real book into speech through the same path as a job and reports characters per second. With `--device both` on a Windows PC with GPU support, it compares the processor and the card.
- `docs/GPU_TESTING_WINDOWS.md` is a step-by-step test plan for a Windows PC with an NVIDIA card.

### Tested

741 automated tests pass on macOS. On Windows, CI downloads the real GPU files and checks the packaged app in three ways. First, the app loads the GPU build of onnxruntime from the downloaded folder. Second, the CUDA and cuDNN libraries load. Third, with **Graphics card** chosen on a machine with no graphics card, the offline voice still speaks on the processor. The GPU path itself has **not yet run on a real NVIDIA card**, which is why this release is marked beta. A full test on an RTX PC is planned next.
