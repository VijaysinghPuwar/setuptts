## SetupTTS v1.7.3

**Better on Windows: files land where you can see them, offline voices start faster and run cooler, and nothing you've rendered gets thrown away.**

---

### Fixes

- **Audio is saved to the Desktop you actually see.** When OneDrive backs up the Desktop (the default on many Windows 10/11 PCs), the real Desktop is `OneDrive\Desktop`. SetupTTS used `C:\Users\<you>\Desktop` instead, so new files went to a folder that isn't on screen — or, if that folder didn't exist, the first Generate failed with *"Save Location Not Found"*.
- **A finished offline or built-in voice file is no longer lost when the old one is open.** Replacing a file that was open in a media player, or selected in Explorer's preview pane, failed at the very last step and discarded the whole render. The new audio is now saved as *"name (2).mp3"* and appears under that name in Recent Conversions.
- **Previews keep playing inside the app.** Pressing **Stop** at just the wrong moment left the audio device open; from then on every preview opened in an outside media player instead.
- **Show in folder** now selects the file even when its folder name has a space or a comma (it opened Documents instead).
- **Downloading an offline voice** no longer fails while Windows Defender is still scanning the new file.
- Opening SetupTTS again while it is running now hands Windows permission to bring the open window to the front, rather than only flashing its taskbar button.
- Error messages from Windows built-in voices are readable on non-English Windows.
- If a proxy is set in Windows settings, its bypass list is checked for the server SetupTTS now connects to, and only once every few minutes rather than for every section.
- Windows' reserved file names (such as `COM¹`, `CONIN$`) are refused with a clear message.
- The installer now requires Windows 10 version 1809 or later, which the app has always needed, instead of installing an app that can't start.

### Faster

- **Offline voices load about twice as fast** — the voice model was loaded twice — and **use about 30% less CPU** at the same speed, so long offline jobs run cooler and quieter, and laptops last longer on battery.

### Tested

526 automated tests on Windows. Stress-tested with a real book chapter at 1×, 2×, 10× and 20× length running at the same time with Andrew; every online, offline and Windows built-in voice through hostile text, fast speech and 30 000-character jobs; and the packaged Windows app's own self-test.
